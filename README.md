# Idea — мобильное приложение на Kotlin

**Idea** — это Android-приложение для сбора, обсуждения и модерации идей. Пользователи могут предлагать свои идеи, а администраторы — принимать или отклонять их. Проект построен на **Kotlin** с использованием **Supabase** в качестве бэкенда (аутентификация, база данных, реальное время).

![Экран входа](login.png)

## Возможности

### Текущие
- **Авторизация пользователей**  
  Регистрация и вход по email/паролю через Supabase Auth.
- **Добавление идей**  
  Любой авторизованный пользователь может отправить идею, указав заголовок и описание. После отправки идея получает статус «На рассмотрении».
- **Модерация администратором**  
  Пользователи с правами администратора видят список новых идей и могут принять (статус «Принято») или отклонить (статус «Отклонено») каждую из них.
- **Мгновенное обновление**  
  Благодаря Supabase Realtime изменения статусов и новые идеи появляются без перезагрузки экрана.

## Технологии
- **Язык**: Kotlin
- **UI**: Jetpack Compose
- **Бэкенд**: Supabase (Auth, PostgreSQL, Realtime)
- **Архитектура**: Clean Architecture + MVVM
- **Асинхронность**: Kotlin Coroutines + Flow

## Требования
- Android 6.0 (API 23) или выше
- Для сборки: Android Studio Hedgehog | 2023.1.1 или новее
- Учётная запись в Supabase (для настройки своего бэкенда)

## Установка и запуск
- Проект в Supabase более не существует, поэтому приложение не функционально. Создавалось исключительно в обучающих целях
- Для запуска потребуется создать собственный Supabase проект и реверс-инженерией создать там SQL-таблицы

### Настройка приложения
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/yourusername/idea-bank-android.git
   ```
2. Откройте проект в Android Studio.
3. В файле `local.properties` (или в `BuildConfig`) добавьте ключи Supabase:
   ```
   SUPABASE_URL=https://yourproject.supabase.co
   SUPABASE_ANON_KEY=your-anon-key
   ```
4. Соберите и запустите приложение на эмуляторе или устройстве.

## Использование

### Для обычного пользователя
1. Войдите в приложение.
2. На главном экране нажмите кнопку «+» (или «Добавить идею»).
3. Заполните заголовок и описание, отправьте идею.
4. Отслеживайте статус своей идеи в списке «Мои идеи».

### Для администратора
1. Войдите под учётной записью, помеченной в базе как `role = 'admin'`.
2. Просматривайте новые идеи, нажимайте «Принять» или «Отклонить».
3. Статус идеи мгновенно обновляется у всех пользователей.
